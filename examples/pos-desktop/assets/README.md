# Studio Market — Desktop POS

Modern desktop POS showcasing newly added SDK widgets as native Studio components.

Uses `scaffold`, `menu_bar`, `app_bar`, `sidebar`, `breadcrumb`, `tabs`, `grid`, `card`, `badge`, `tag`, `avatar`, `data_table`, `chart`, `calendar`, `color_picker`, `kbd`, `rating`, `progress_indicator`, `status_bar`, `dialog`, `toast`, `command_palette`, etc. — all rendered via the closed protocol without HTML/CSS.
