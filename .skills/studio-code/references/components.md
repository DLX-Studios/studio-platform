covers each kind with its accepted props, child shape, event/state notes, support
limits, and a compiler-checked Studio Script example. Read only the relevant family.

**Start here:** [Box, the general div-like wrapper](components/layout.md#box),
then [shared contracts and reactive examples](components/contracts.md).

Examples validate source syntax/lowering, not live window behavior or every mount-time value.
Support notes are based on the current protocol/renderer; generic surfaces and known
contract gaps are deliberately identified. For the installed version, use its actual
compiler diagnostics and preview rather than assuming parity with upstream widgets.

In a platform checkout, the reference sources are `crates/studio-protocol/src/ui.rs`,
`properties.rs`, `crates/studio-components/src/native_view/renderer.rs`, `events.rs`,
and `crates/studio-script/src/validate.rs` / `lower_studio.rs`.

To recheck the examples and catalog coverage, run the bundled
`scripts/check_components.py` from this skill folder or by absolute path.
Use `--platform-root PATH` to also compare coverage with a platform checkout.
