# Data Model

Route entry: pattern, parameter names, title, relative source, static/param/wildcard classification. Layout chain: ordered ancestor +layout.studio files. Component import: local binding, canonical .studio source, source span. Instance: scoped identities, bound/default props, state, derived values and handlers. Project routing metadata: schemaVersion 1 and bounded entries mapping patterns to compiled component IDs. Navigation state: existing owner-bound stack, active concrete route and resolved component, retained per-route sessions.
